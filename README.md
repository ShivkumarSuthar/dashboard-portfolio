# 🧩 Dashboard Portfolio

A full-stack MERN Dashboard Portfolio consisting of:

- **Frontend** – built with React or Next.js
- **Backend API** – built with Node.js and Express


## 📂 Project Structure
dashboard-portfolio/
├── frontend/ # React/Next.js app
├── api/ # Node.js + Express API
├── README.md


## ⚙️ Prerequisites

- **Node.js** `v20.x`  
  Install using [nvm](https://github.com/nvm-sh/nvm):
  
  ## base
  curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
  nvm install 20
  nvm use 20



🚀 Getting Started
1. Clone the Repository
    1. git clone https://github.com/ShivkumarSuthar/dashboard-portfolio.git
    2. cd dashboard-portfolio

# Frontend
    cd frontend
    npm install --legacy-peer-deps

# Backend API
    cd ../api
    npm install --legacy-peer-deps
    
# Start Backend
    cd api
    npm run dev

# Start Frontend
    cd ../frontend
    npm run dev


📝 Notes
    Ensure environment variables are properly configured (e.g., MongoDB URI, API URLs).

    The project uses Node.js v20 – using another version may cause issues.

    You can use PM2 or Docker for production deployment.
